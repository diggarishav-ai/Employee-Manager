# India Wellness Market — Report Programme

Two linked deliverables, one evidence base.

| File | Report | Reader | Purpose |
|---|---|---|---|
| `00-report-structure.md` | **A — Landowner Opportunity View** | A prospective investor holding a land parcel | Persuade / advise: is a wellness retreat the right use of this land, and how would they participate without operating it? Contains the GTM argument, highest-and-best-use analysis, land-fit scorecard and participation models. |
| `01-operating-analysis-structure.md` | **B — Opportunity & Operating Performance Analysis** | Internal / analytical | Size the opportunity and establish how India's top 20–24 retreats actually perform: occupancy, business model, revenue, pricing, cost structure, capital efficiency. ## Locked parameters
- Horizon **2030**; currency **INR primary**, USD secondary
- Retreat ranking: weighted composite — scale 30% · brand 25% · clinical credibility 25% · momentum 20%
- Panel: 24 properties analysed, top 20 profiled

## Standing principles
1. **Every figure carries a data tier** (T1 hard / T2 derived / T3 modelled / T4 judgement)
   and a source. Nothing is presented as fact that is an estimate.
2. **Normalise before comparing.** Properties differ in revenue architecture — bundled
   programme pricing vs unbundled room-plus-treatment — so all comparisons run on Total
   Revenue per Guest-Night, not room ADR.
3. **The analysis must be able to reach a negative conclusion.** Report A's land-fit
   scorecard is built so it can say this parcel is wrong for wellness. A document that
   concludes "yes" regardless of the evidence is worthless to the reader.
